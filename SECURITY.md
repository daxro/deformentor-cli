# Security Policy

## Reporting A Vulnerability

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/daxro/deformentor-cli/security/advisories/new).

Do not open a public issue for a suspected vulnerability.

Never include session files, cookies, SAML values, authentication links, response bodies, or raw debug logs in any report, including a private report. Describe the issue with synthetic data and redact all credentials.

## Supported Versions

Security fixes target the latest tagged release. Installations from `master` are development builds.

## Scope

Deformentor is unofficial and unaffiliated with InfoMentor or Stockholms stad. Use it only with accounts and data you are authorized to access.
